🚀 DocFX Documentation Deployment Script

This repository contains a PowerShell automation script designed to compile your C# source code XML comments into static HTML documentation using DocFX, and seamlessly deploy those assets to a completely separate GitHub documentation repository.

By using a cross-repository layout and an orphan branch, your source history remains perfectly clean while your website stays completely isolated.

🛠️ Architecture & How It Works

  1. Clean Slate: The script empties the target documentation repository using a custom function (Clear-VisibleFolderContents) that protects hidden files like your .git history.
  2. Safe Branch Swapping: It switches the target repository to the gh-pages branch.
  3. Compilation: It triggers docfx metadata and docfx build from your project folder, rendering the website directly into the /docs folder of your target repository.
  4. Force Deployment: It stages, commits, and force-pushes (git push -f) the fresh HTML files directly to GitHub.
  5. Reset: It cleans the folder one more time and returns the target repository safely back to the main branch so your workspace stays pristine.

📋 Prerequisites

Before running the script, ensure you have the following installed on your machine:

  • PowerShell 7+ (Recommended) or Windows PowerShell
  • Git (Configured with access to your GitHub account)
  • DocFX CLI (Added to your system's Environment Variables PATH)

⚙️ Repository Setup

To ensure the script runs flawlessly, your local folders must be organized exactly like this on your hard drive:

📁 Your-Development-Directory/
├── 📁 NmsAmqpClient/           <-- This repository (Contains the source code and script)
│   ├── docfx.json
│   └── deploy-docs.ps1
└── 📁 NmsAmqpClient-Docs/      <-- The dedicated documentation repository
    ├── .git/
    └── docs/                   <-- GitHub Pages reads from this folder

GitHub Pages Configuration

  1. Go to your NmsAmqpClient-Docs repository on GitHub.
  2. Navigate to Settings > Pages.
  3. Under Build and deployment, set the Source to Deploy from a branch.
  4. Set the Branch to gh-pages and the folder to /docs.

🚀 How to Run the Script

Open a PowerShell terminal, navigate to your project directory, and execute the script:

./deploy-docs.ps1

🤫 Note on Line Ending Warnings

The script automatically configures your local Git environment using these flags:

git config core.safecrlf false
git config core.autocrlf false

This guarantees that DocFX's native LF web assets are accepted by Git silently, completely preventing terminal flooding and keeping your build logs clean.

⚠️ Important Considerations

  • Overwriting Remote History: The script uses a force-push (git push -f). It will completely overwrite whatever is currently on the GitHub gh-pages branch with your latest local build.
  • Zero Commit Protection: The script includes a safety check that scans for code changes. If you run the script and your source code hasn't changed, it will cleanly skip the Git commit and push phases to prevent script crashes.
